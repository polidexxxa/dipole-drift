# Dipole Drift («Дипольный дрейф»)

Браузерная 2D-аркада со сменой полярности игрового персонажа и кампанией из 15 секторов. Учебный проект, выполненный в рамках большого домашнего задания по дисциплине «Генеративный искусственный интеллект: модели и методы» с использованием платформы WebSim.

> **Онлайн-версия (WebSim):** `https://websim.com/@greedydandelion1890052/dipole-drift`

## О проекте

Игрок управляет заряженной частицей, которая может переключать полярность между положительной (`+`, голубой цвет) и отрицательной (`−`, оранжевый цвет). Полярность определяет взаимодействие с платформами, силовыми полями и препятствиями:

- **Платформы:** противоположный заряд служит устойчивой опорой, совпадающий — даёт импульс отталкивания; также реализованы нейтральные, движущиеся, переключающиеся и магнитные платформы.
- **Силовые поля и препятствия:** вертикальные поля, ветровые зоны, радиальные узлы, зоны запрета смены заряда (`NO-FLIP ZONE`), фазовые и вращающиеся лазеры, пульсирующие преграды и призмы.
- **Кампания:** 15 заранее подготовленных секторов (включая сектор с инвертированной гравитацией). В каждом секторе нужно собрать 5 осколков, чтобы активировать выходной портал.
- **Прогресс и звук:** сохранение пройденных секторов и точки продолжения через `localStorage`, процедурная генерация музыки и звуковых эффектов средствами Web Audio API (без внешних аудиофайлов).

## Управление

| Клавиша | Действие |
|---|---|
| `A` / `D` или `←` / `→` | Горизонтальное движение |
| `W` или `↑` | Прыжок с опоры; специальное действие при инвертированной гравитации или магнитном контакте |
| `S` или `↓` | Ускорение вниз, отсоединение от магнитной платформы или проход через переключающуюся платформу |
| `Space` | Смена полярности (вне зоны запрета) |
| `R` | Перезапуск текущего сектора |
| `Esc` / `P` | Пауза и возврат в игру |
| `L` | Открытие экрана выбора секторов |
| `M` | Включение / отключение звука |
| Стрелки + `Enter` | Навигация и выбор пунктов в меню |

## Локальный запуск

Игра написана на HTML, CSS и JavaScript (Canvas 2D) без внешних библиотек. Поскольку `game.js` подключён как ES-модуль (`<script type="module">`), открывать `index.html` нужно через локальный HTTP-сервер, а не напрямую по протоколу `file://`.

Пример запуска с помощью Python:

```bash
python -m http.server 8000
```

После запуска открой в браузере адрес `http://localhost:8000`.

## Известные ограничения

- Игра рассчитана на настольный компьютер или ноутбук с клавиатурой; сенсорное управление для мобильных устройств не реализовано.
- Прогресс хранится локально в браузере (`localStorage`) и не синхронизируется между устройствами.
- В текущей версии сохраняются незначительные особенности интерфейса (клавиатурная навигация по сетке выбора секторов, область кнопки `MENU` на экране результата, сохранение предыдущего фокуса результата; нажатие `R` увеличивает счётчик смертей).
